# FS Webworks

Hemsidor för hantverkare och småföretag i Stockholm.

- Enkel sida: **9 900 kr**
- Drift: **690 kr/mån**
- Extraarbete: **950 kr/tim**

Kontakt: [fredrik@fswebworks.se](mailto:fredrik@fswebworks.se)

## Stack

Vite 8 + TanStack Start (React 19, TypeScript, Tailwind v4).

## Lokal utveckling

```bash
npm install
npm run dev
```

Bygg:

```bash
npm run build
```

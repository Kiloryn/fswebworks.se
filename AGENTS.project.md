# FSwebworks — how design skills work

Do not run Hallmark, frontend-design, and web-design-guidelines as three
votes on the same pixel. They are **one pass**, in this order. A later
skill may only *add* what the earlier one cannot see. It may not undo
the earlier one's job.

## Pipeline (mandatory)

1. **frontend-design** — What room is this?
   Subject, density, type, photo, layout that belongs to *this* firm.
   Fill it. Linné is the quality bar for an example page: committed,
   not a letter with a hex swap.

2. **Hallmark** — What in that room is a tell?
   Cut italic headers, fake 4.8 Google, three identical quote cards,
   tracked eyebrows, gallery-of-thumbs on the agency homepage.
   **Do not empty the room.** Do not replace a salon split with a
   max-w-3xl list because “restraint”.

3. **web-design-guidelines** — Can a person use it?
   Tap targets, contrast, focus, empty grid cells, alt on linked
   images, forms. Fix function. Do not flatten a colour-field hero
   for “consistency”.

4. **visual-qa** — Last look before “done”.
   No Pic as a direct grid child. No empty column. Screenshot if the
   user sent one.

## Locked (not up for skill debate)

- FSwebworks itself: cream paper, Fraunces, 9 900 kr, Swedish copy.
- Example pages: each is a different room (not skins of one template).
- User direction always wins the pipeline.

## Forbidden

- Three separate audits that contradict each other in one reply.
- Using Hallmark as a scissors on content frontend-design just put in.
- Using frontend-design to re-skin Hallmark-clean chrome with moodboard.
- Loading all three skill files “just in case”. Load the step you are on.
